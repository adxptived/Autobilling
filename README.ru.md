## Что такое Autobilling?

Autobilling — это расширение для браузера, которое генерирует **номера карт, проходящие проверку Луна**, с соответствующими платёжными данными (имя, адрес, город, индекс, страна, телефон, email) и **автозаполняет их в платёжные формы** — Stripe, Stripe Elements и обычные HTML-поля.

Используйте для тестирования платёжных сценариев, QA или разработки — не для реальных транзакций.

## Что генерирует

- Номер карты (проходит алгоритм Луна)
- Срок действия (ММ/ГГ)
- CVV (3 или 4 цифры в зависимости от платёжной системы)
- Полное имя
- Адрес
- Город, регион/область, почтовый индекс
- Страна (27+ стран)
- Номер телефона с реалистичными префиксами стран
- Email

## Быстрая установка

### Chrome / Edge / Brave / Opera

1. Скачайте или клонируйте репозиторий
2. Выполните в терминале:
   ```bash
   npm install
   npm run build
   ```
3. Откройте страницу расширений браузера:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Brave: `brave://extensions`
   - Opera: `opera://extensions`
4. Включите **Режим разработчика** (переключатель вверху справа)
5. Нажмите **Загрузить распакованное расширение** и выберите папку `dist`
6. Закрепите расширение на панели инструментов

### Firefox

Требуется Firefox 142 или новее.

1. Скачайте или клонируйте репозиторий
2. Выполните в терминале:
   ```bash
   npm install
   npm run build
   ```
3. Откройте `about:debugging#/runtime/this-firefox`
4. Нажмите **Загрузить временное дополнение**
5. Выберите `dist-firefox/manifest.json`

### Windows (в один клик)

Запустите `install.bat` — он установит зависимости, соберёт расширение и откроет страницу расширений.

## Как использовать

| Действие | Как |
| --- | --- |
| Сгенерировать новую карту | Нажмите **Generate** |
| Заполнить форму оплаты | Нажмите **Autofill Form** или `Ctrl+Shift+F` |
| Заполнить через контекстное меню | Правый клик на странице → **Autofill card** |
| Скопировать все данные разом | Нажмите **Copy all** |
| Скопировать одно поле | Кликните по значению (номер карты, expiry, CVV, имя и т.д.) |
| Сменить платёжную систему | Выберите **BIN** (банковский префикс) из списка |
| Сменить страну | Выберите **Country** из списка |
| Добавить свой BIN | Введите префикс в **Custom BIN** → **Add** |
| Добавить в избранное | Нажмите ☆ рядом с селектором BIN или страны |
| Сменить профиль | Выберите **Generated**, **US**, **NL** или **Custom** в секции Billing |
| Открыть настройки | Нажмите **⚙ Settings** в шапке расширения |

## Настройки

Нажмите **Settings** в окне расширения для доступа к настройкам:

- **Session only** — данные карты и профиля не сохраняются между сессиями
- **Auto country by URL** — автоопределение страны по домену вкладки (.de, .fr, .jp и т.д.)
- **History retention** — автоочистка истории через 15 мин, 1 час, 24 часа или хранение до ручной очистки
- **Compact card** — компактный вид карты по умолчанию
- **Live BIN lookup** — показывает информацию о банке/стране для неизвестных BIN (опционально, через binlist.net)
- **Phone & Email** — включение генерации телефона и email
- **Custom profile** — сохранение своего имени, адреса, города, индекса, региона, телефона, email и страны
- **Custom BINs** — управление сохранёнными BIN-префиксами (просмотр, удаление по одному)
- **Export / Import** — резервное копирование и восстановление настроек в JSON
- **Reset** — очистка истории или сброс всех настроек к значениям по умолчанию

## Профили

| Профиль | Описание |
| --- | --- |
| **Generated** | Случайное имя + адрес + город из пула выбранной страны |
| **US** | Фиксированный адрес США: 221B Baker Street, New York, NY 10001 |
| **NL** | Фиксированный адрес Нидерландов: Damrak 1, Amsterdam, 1012 LG |
| **Custom** | Ваш сохранённый профиль (редактируется в Настройках) |

## Поддерживаемые платёжные системы

Visa, Mastercard, American Express, Discover, UnionPay, JCB, Diners Club — через встроенные и пользовательские BIN, а также через живой поиск.

## Поддерживаемые страны (27+)

US, GB, DE, FR, IT, ES, JP, CA, AU, NL, BR, MX, IN, KR, TR, AE, AR, CL, TH, GR, HU, RO, ZA, IL, ID, PH, VN, TW, HK, AT, BE, CH, CZ, DK, FI, IE, NO, NZ, PL, PT, SE, SG — каждая с реалистичными городами, регионами, форматами индексов и телефонными префиксами.

## Приватность

Все данные остаются на вашем устройстве. Единственный внешний запрос — **опциональная** проверка BIN через `lookup.binlist.net` (отправляются только первые 6–8 цифр номера карты — банковский префикс). Полные номера карт, CVV, имена и адреса никуда не отправляются.

Подробнее в [PRIVACY.md](PRIVACY.md).

## Предупреждение об ответственности

Autobilling предназначен **только для разработки, QA и легитимного тестирования**. Не используйте его для мошенничества, несанкционированных транзакций, обхода платёжных систем или нарушения законов и условий платформ. Вы несёте ответственность за использование расширения.
